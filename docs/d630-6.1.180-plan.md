# D630 Debian 6.1.180-1: implementation plan and acceptance tests

## Why a separate workflow pair

The previous build path targeted 6.1.187-1 and used an old config package version that was no longer available in APT metadata. An earlier config audit also asked for the wrong Sigmatel symbol and treated DEBUG_FS/CONFIGFS as unwanted filesystems. The replacement uses two explicit workflows and one shared build script so the normal and RT build differences are limited to Debian's native feature set and expected release.

## Inputs and source integrity

- Pinned source: Debian linux 6.1.180-1, downloaded from the official Bookworm security source pool.
- Debian's .dsc source descriptor is used by dpkg-source to verify source archive checksums.
- Current Bookworm build dependencies supply build tooling; the build does not ask APT for the old config package version.
- The Intel microcode blob is checked for T7250 CPUID 0x000006fd. The exact 3945ABG firmware requested by iwl3945 is extracted from firmware-iwlwifi.
- The CPU microcode and 3945ABG firmware are embedded as extra firmware, and their exact bytes are checked against vmlinux. The original official firmware .debs and microcode license information are published as sidecars.

## Kernel config

Each run first asks Debian's own rules to generate the selected feature-set config, copies that baseline to audit, appends the D630 fragment to only the matching image target, then runs olddefconfig. The policy helper removes unrelated sound codecs, filesystems, vendor GPUs and explicitly excluded hardware families. It deliberately does not rewrite the Makefile version or Debian ABI/localversion. The audit saves a unified config diff plus a TSV classifying each changed symbol.

The target includes Core 2 CPU tuning, MSR, zram built in with all Linux 6.1 compressors, built-in ext4/NTFS3/Btrfs/FAT-family/UDF and SquashFS compression support, Intel i915 baseline values, Intel 3945ABG firmware, Sigmatel/IDT audio, PS/2 touchpad, SCSI disk/CD and USB storage, and nftables FIB support.

## Package identity

- amd64: `linux-image-6.1.0-52-amd64_6.1.180-1+d6301_amd64.deb`.
- amd64-rt: `linux-image-6.1.0-52-rt-amd64_6.1.180-1+d6301_amd64.deb`.

The package names and kernel/module release paths match the original Debian ABI, while the higher custom package version makes the rebuild identifiable. The image is a custom unsigned package; it is not the Debian-signed binary.

## Acceptance checklist

- Source descriptor/version matches exactly 6.1.180-1.
- Correct normal/RT setup and binary image targets are used.
- Config audit passes CPU, module, storage, sound, Wi-Fi, firmware, compression and RT assertions.
- Firmware blob bytes appear in vmlinux; appropriate loadable modules are present under the exact ABI release.
- Debian package metadata, expected boot image/module path, and SHA256SUMS are validated.
- Artifact upload fails if files are missing; a unique pre-release publishes the packages and audit report only after all checks pass.
- Hardware boot and subsystem tests are still required on the real D630.
