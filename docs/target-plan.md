# Target contract — Debian 12 / Dell Latitude D630

## Pinned Debian source

- Source package: `linux=6.1.180-1` from Bookworm security.
- Debian amd64 reference image ABI: `6.1.0-52-amd64`.
- Custom kernel release/module directory: `6.1.180-d630-core2`.
- Output package: `linux-image-6.1.180-d630-core2`, version `6.1.180-1+d6301`, architecture `amd64`.

## Configuration policy

- Start from the configuration generated by Debian's native amd64 image setup target.
- Require `CONFIG_MCORE2=y` and `CONFIG_GENERIC_CPU=n`.
- Require `CONFIG_CPU_FREQ=y`, `CONFIG_CPU_FREQ_GOV_USERSPACE=y`, and `CONFIG_X86_ACPI_CPUFREQ=m`.
- Preserve Debian's active settings for Intel GM965/i915 and AGP, SATA/AHCI, optical and USB mass storage, ACPI, input, nftables FIB, and required userspace security facilities.
- Retain Intel PRO/Wireless 3945ABG, Intel ICH8/Sigmatel HDA audio, PS/2 input and GPM's legacy mouse interface.
- Keep ext4, Btrfs, NTFS3, FAT/VFAT/exFAT, UDF, ISO9660 and SquashFS; retain built-in zram with LZ4 as default.
- Embed T7250 microcode and Intel 3945ABG firmware; validate firmware and provide official firmware packages and license/copyright notices.
- Set `CONFIG_DEBUG_INFO_NONE=y`; do not build debug-symbol or development packages.
- Explicitly prune unrelated bus/protocol families, NVMe, unused SCSI adapters, other GPU vendors, unused sound devices, tuner/DVB/radio/SDR/test hardware and unrelated device modules.

## Deterministic build

Patch only Debian's standard amd64 runtime image setup/build target so its ABI/localversion, generated `KERNELRELEASE`, boot path and modules directory agree on `6.1.180-d630-core2`. Stop before the long compile if generated kernel release differs.

The final audit classifies Kconfig changes. Unexplained module drops, Kconfig override/choice warnings, missing required symbols/modules/firmware, incorrect release or inconsistent package metadata fail the build. Publish only a validated package.

## Maintenance and hardware test

Pin each source release deliberately and update the source version and official Debian ABI together when moving to a newer security release. Hosted CI cannot prove the laptop boots; keep a known-good kernel/initramfs and test boot, storage, graphics, Wi-Fi, audio, touchpad, CPU frequency scaling and nftables/firewalld on the actual D630.
